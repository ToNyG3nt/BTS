\section{Partie I : Questions de cours}
\begin{enumerate}
    \item Quelles sont les 7 couches du modèle OSI et leurs roles principal?\\
    \begin{itemize}
        \item Couche 1 - Physique : Transmission des bits sur le support physique.
        \item Couche 2 - Liaison de données : Assure la communication entre deux nœuds directement connectés.
        \item Couche 3 - Réseau : Gère l'adressage et le routage des paquets entre les réseaux.
        \item Couche 4 - Transport : Assure la livraison fiable des données entre les hôtes.
        \item Couche 5 - Session : Gère les sessions de communication entre les applications.
        \item Couche 6 - Présentation : Traduit les données entre le format réseau et le format application.
        \item Couche 7 - Application : Fournit des services réseau aux applications utilisateur.
    \end{itemize}
    \item Quelle est la différence entre le modèle OSI et le modèle TCP/IP?\\
    Le modèle OSI est un modèle théorique en 7 couches, tandis que le modèle TCP/IP est un modèle pratique en 4 couches utilisé pour l'Internet.
    \item Expliquez les notions suivantes : Protocole, service, primitive, entité.
    \begin{itemize}
        \item Protocole : Ensemble de règles régissant la communication entre entités.
        \item Service : Fonctionnalité fournie par une couche à une autre.
        \item Primitive : Opération de base fournie par une couche.
        \item Entité : Instance d'une couche communicante.
    \end{itemize}
    \item Donnez un exemple de protocole de chaque couche du modèle OSI.\\
    \begin{itemize}
        \item Couche 1 - Physique : Ethernet (câblage)
        \item Couche 2 - Liaison de données : Ethernet (trame)
        \item Couche 3 - Réseau : IP (Internet Protocol)
        \item Couche 4 - Transport : TCP (Transmission Control Protocol)
        \item Couche 5 - Session : NetBIOS
        \item Couche 6 - Présentation : SSL/TLS
        \item Couche 7 - Application : HTTP (Hypertext Transfer Protocol)
    \end{itemize}
\end{enumerate}
