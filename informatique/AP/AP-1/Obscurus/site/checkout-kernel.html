Anticheat Kernel

Le driver Obscurus s'initialise en Ring 0 avant même que le processus de jeu ne démarre. Il surveille en temps réel les tentatives les plus avancées de contournement — celles que les solutions userland ne voient tout simplement pas.

Ce qui est inclus

  • Driver Ring 0 signé WHQL Microsoft, compatible Windows 10/11 (toutes éditions)
  • Détection des injections DLL, manual mapping et shellcode en mémoire noyau
  • Protection contre les attaques DMA (Direct Memory Access via carte PCIe externe)
  • Surveillance des hooks posés sur les appels système critiques (SSDT, DKOM)
  • Détection des processus suspects et des pilotes non signés en arrière-plan
  • Réponse configurable : ban immédiat, shadow ban différé ou alerte dashboard
  • 0 BSOD imputable à Obscurus sur 18 mois de production en conditions réelles
  • Testé sur 200+ configurations matérielles (Intel / AMD, DDR4 / DDR5)
  • SDK d'intégration C++ avec documentation complète et exemples de code
  • Dashboard de gestion en temps réel : bans, alertes, logs d'événements
  • Mises à jour du driver sans redémarrage du serveur de jeu
  • Support technique dédié (réponse < 2h pour incidents critiques clients)
